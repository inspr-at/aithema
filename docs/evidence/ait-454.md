# AIT-454 evidence

PR: https://github.com/inspr-at/aithema/pull/408. Tick spec v1 requires 0 px movement in 50/50 runs at 390 px in DE and EN. All browser evidence below came from offline fixtures on mbp2606.

A duplicate refresh of the same verified identity cleared the open address edit when a reply finished. The form switched from capture to verified mode and emptied `.verify__note`, shrinking it from 31.1875 px to 15.59375 px. The centered dialog therefore moved 7.796875 px at re-enable, before the first animation frame. Fonts were already loaded, and the reason slot stayed at 33.265625 px throughout.

The fix is `packages/ui/src/verification.js:119` (commit `a93a01a1`): keep the edit open when the same verified address is acknowledged again. A newly verified identity or changed address still ends the edit. Copy, CSS and the existing 0 px assertions are unchanged.
